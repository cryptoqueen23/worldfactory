# World Factory Immersive Website

This directory contains the conventional, accessible World Factory marketing website. It is intentionally separate from the IWSDK XR application at the repository root.

## Visual direction

Black, deep red and metallic gold. The phoenix motif is part of the World Factory identity. The website remains usable without entering XR.

## Promo video

The page expects the promotional MP4 at:

`website/assets/world-factory-promo.mp4`

The video is intentionally not required for the page to function. A branded fallback is shown when the asset is absent. Autoplay is muted, and visitors can pause/play the film. When the operating system requests reduced motion, autoplay is disabled.

## XR link

The “Enter Immersive Experience” actions currently link one directory up to the IWSDK app. Deployment routing can be adjusted once the final production URLs are chosen.
